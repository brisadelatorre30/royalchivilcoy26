# Royal Prestige Chivilcoy

Sitio web de una sola página para el emprendimiento de asesoramiento y venta de **Royal Prestige** en Chivilcoy, Buenos Aires, Argentina. Permite a los clientes ver el catálogo, armar un carrito, cotizar y contactar directamente a la asesora.

🌐 **Sitio en vivo:** [royalchivilcoy26.vercel.app](https://royalchivilcoy26.vercel.app/)

---

## Sobre el proyecto

Este sitio fue desarrollado como **Trabajo Final Integrador** de la *Diplomatura en IA Aplicada a Entornos Digitales de Gestión* (FCE-UBA, Cohorte 2026).

El objetivo es contar con una vitrina digital propia donde el cliente pueda ver los productos, seleccionarlos y solicitarlos, y donde la asesora pueda modificar contenidos, imágenes y datos de contacto cada vez que sea necesario.

**Autora:** Brisa de la Torre

## Funcionalidades

- 🛍️ **Catálogo de productos:** ollas y sartenes de distintas medidas, cuchillos, cuchillas, tablas de picar, hervidores, tazas y más, cada uno con su imagen.
- 📖 **Historia de Royal Prestige.**
- 🔬 **Materiales:** información sobre el acero quirúrgico con el que están fabricados los artículos.
- 🛒 **Carrito de compras.**
- 💳 **Cotizador:** pago en efectivo, tarjetas de crédito, descuento por pago en efectivo y cupones de descuento.
- 📞 **Contacto y asesoramiento en Chivilcoy:** correo y redes sociales.
- 📱 **Diseño responsive**, moderno y con mucho espacio en blanco.

## Diseño

- **Paleta:** azul, acero quirúrgico, rojo y blanco.
- **Tipografía:** elegante y legible.
- **Tono:** acorde al carácter de la marca.

## Cómo se creó

El sitio se generó con un único prompt estructurado en cuatro partes (**Rol, Tarea, Formato y Contexto**):

- **Rol:** diseñador profesional de páginas web.
- **Tarea:** sitio web de una página para Royal Prestige Argentina.
- **Formato:** código HTML, CSS y JavaScript en un único archivo.
- **Contexto:** catálogo, historia, materiales, carrito, cotizaciones, datos de contacto, paleta, tipografía y diseño responsive.

Lo único que se modificó luego fueron las imágenes, reemplazadas por las oficiales de la marca.

## Uso local

No requiere instalación ni dependencias:

1. Cloná el repositorio:
   ```bash
   git clone https://github.com/brisadelatorre30/royalchivilcoy26.git
   ```
2. Abrí `index.html` en tu navegador.

## Despliegue

El repositorio está conectado a **Vercel**: cada cambio que se sube a GitHub se publica automáticamente en el sitio.

## Mantenimiento

Para actualizar precios, productos, cupones, imágenes o datos de contacto, se edita el código del archivo `index.html` (o se solicita la modificación a la IA) y se sube el cambio al repositorio.

## Limitaciones conocidas

- No tiene back-end ni base de datos: las solicitudes de los clientes llegan únicamente por correo.
- No hay gestión de stock ni panel de administración.
- Precios, descuentos y cupones deben revisarse y actualizarse manualmente.
